# GEMINI.md

Please see the complete guidelines and rules in [AGENTS.md](./AGENTS.md).

Summary of Inviolable Workspace Rules:
1. **Language**: English strictly for all code, identifiers, tests, and commit messages.
2. **Git**: Never push to GitHub (`git push` is strictly forbidden). Keep all Git work local.
3. **Coverage**: 90% backend test coverage target (audited with JaCoCo warnings). Frontend tests are not required.
4. **Persistence**: Validate data integrity, transactions, and explicit persistence verification.
5. **Architecture**: Scalable and performant (Java 21 Virtual Threads, Angular Signals, Tailwind CSS).
6. **Design Patterns**: Implementation plans must leverage suitable design patterns (Strategy, Factory, Adapter, Container-Presentational).
